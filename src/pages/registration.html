Sign Up in the Parimatch App or Mobile Browser

The sign-up form is the same on a computer, in a mobile browser and in the Parimatch app. One account works everywhere, with the same balance and bonus.

Android App (APK)

  1. Open Parimatch in Chrome and tap the App button.
  2. Download the Android APK; the app is not on Google Play.
  3. Allow installs from unknown sources for Chrome if asked, then install.
  4. Open the Parimatch app, tap «Sign up» and complete the form.

iPhone Web App

  1. Open Parimatch in Safari.
  2. Tap Share, then «Add to Home Screen» and «Add».
  3. Open the new icon on the home screen.
  4. Tap «Sign up» and complete the form.

Signing up in Chrome, Safari or another mobile browser needs no download at all. For players who install the web app, Parimatch also lists a PWA Welcome offer: a 400% bonus pack up to ₹1,80,000 in rewards, with the split and terms shown only after registration. Device requirements and install details are on the Parimatch app page.

Common Registration Problems

  • The SMS code does not arrive. Wait about 60 seconds, check that DND does not block service messages, then request the code again.
  • The e-mail link has expired. Request a new confirmation e-mail and open the link soon after it arrives.
  • The number or e-mail is already registered. Log in with that contact or reset the password on the Parimatch login page.
  • The form does not load. Clear the browser cache or switch to the Parimatch app.
  • The bonus was not chosen. The welcome offer is tied to the first deposit, so select it in the sign-up form or on the deposit screen before paying.
  • Personal data does not match the ID. Name and date of birth are checked during verification, so enter them exactly as on Aadhaar or PAN.

If a problem persists, Online Chat answers 24/7; see the Parimatch support page. Support does not message players first on WhatsApp and never asks for a password or OTP.

FAQ About Parimatch Registration

Is a promo code needed to register at Parimatch?

No. The welcome bonus is selected in the sign-up form, which has no promo-code field. Campaign codes are entered later in Promotions → Promo code.

Can I register at Parimatch with an e-mail instead of a phone number?

Yes. The form offers a +91 phone number, e-mail, Google and Apple. An e-mail sign-up is confirmed through a link sent to the inbox.

What is the minimum age for Parimatch registration?

18. Age is confirmed with a checkbox in the form and checked again during verification.

Do I need to verify the account right after signing up?

No. Deposits and bets work right away. Verification with Aadhaar, PAN or another ID is needed before the first withdrawal.

Can the welcome bonus be changed after registration?

Usually not. The offer chosen in the form cannot be switched later, and only one welcome bonus is available per person, so decide before the first deposit.

Which currencies can a Parimatch account use?

INR is the main account currency, with a separate crypto balance in USDT or USDC. The currency is usually fixed at sign-up, so pick it before the first deposit.
