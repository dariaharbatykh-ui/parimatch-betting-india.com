How to Add Parimatch to the Home Screen

A home-screen icon turns the mobile site into a web app, also called a PWA. Parimatch then opens from the icon like an ordinary app, with no APK to install, and the web app updates itself.

iPhone and iPad: Safari

  1. Open Parimatch in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen, then Add.
  4. Open the new icon and log in.

Android: Chrome

  1. Open Parimatch in Chrome.
  2. If an install or Add to Home screen prompt appears, accept it.
  3. Otherwise, tap the three-dot menu and choose Add to Home screen or Install app.
  4. Confirm and launch Parimatch from the icon.

On iPhone, the home-screen web app is the main way to use Parimatch like an app, since no App Store app is available in India. Push notifications for home-screen web apps need iOS 16.4 or newer.

Fixing Common Problems on the Mobile Site

  • The page does not load. Reload, clear the browser cache, switch between Wi-Fi and mobile data or try another browser. The Help Centre also has a dedicated article, «Website or App not Working/Loading Properly».
  • Odds refresh slowly or a live bet is rejected. Live odds change fast, and a slow connection delays updates. Refresh the event page, move to a stronger signal and place the bet again at the new odds.
  • The account logs out without warning. Sessions end after a period of inactivity. Log in again, or use «Forgot your password?» to set a new password of 4+ characters if the old one no longer works.
  • A UPI payment went through but the balance did not change. Return to the browser and wait a few minutes before paying again. If the balance is still unchanged, contact Online Chat with the payment details from the UPI app.
