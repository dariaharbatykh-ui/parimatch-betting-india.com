How to Log In to Parimatch on Any Device

The login steps are almost the same everywhere. Pick the card that matches the device in hand.

Desktop & Mobile Browser

  1. Open Parimatch in Chrome, Safari or any other browser.
  2. Click or tap “Log in”.
  3. Choose phone, e-mail or account ID, or tap Google or Apple.
  4. Enter the number after +91, the e-mail or the ID, then the password.
  5. Confirm with the SMS code if asked. The balance and the Deposit button appear in the top right corner.

Android App

  1. Open the Parimatch app installed from the APK file.
  2. Accept the update prompt if one appears.
  3. Tap “Log in” and choose the same method used at Parimatch sign-up.
  4. Enter the details and the SMS code if requested.

iOS Web App

  1. Open the Parimatch icon added through Safari → Share → Add to Home Screen.
  2. Tap “Log in”.
  3. Use the Apple button for an Apple account, or enter the phone, e-mail or ID with the password.
  4. Confirm the code if asked. The web app updates itself, so no reinstall is needed.

The mobile version and the app share one account, one balance and the same bet history. Differences between the two are covered on the Parimatch mobile version page, and installation is explained on the Parimatch app page.

Parimatch Password Reset Step by Step

A lost password is not a reason to open a second account. Parimatch allows one account per person, and multi-accounting voids any bonus. Recover the existing account instead:

  1. Open the login form. In a browser, on the mobile version or in the Parimatch app.
  2. Tap “Forgot your password?” The link sits inside the login form.
  3. Choose how to recover. Phone number, e-mail or account number, whichever belongs to the account.
  4. Enter the code. A one-time code arrives by SMS or e-mail. Type the code into the recovery form.
  5. Create a new password. At least 4 characters; a longer mix of letters and digits is much harder to guess.
  6. Log in again. The new password works in the browser, on the mobile version and in the app.

If no code arrives or the form keeps rejecting the details, the Online Chat answers 24/7 in English and Hindi. Other contact options are listed on the Parimatch support page.

Account Security Tips for Parimatch Players

A betting account holds money and KYC documents, so a few simple habits go a long way.

  • Use a unique password. Never reuse the password from e-mail, UPI apps or social media.
  • Never share an OTP or password. Not with friends, tipsters or anyone claiming to help with a withdrawal.
  • Keep the phone number and e-mail current. Password recovery codes go only to the contacts saved in the account.
  • Log out on shared devices. Office PCs and borrowed phones keep sessions open otherwise.
  • Install the APK only through “Download for Android” on Parimatch. Files from forums and file-sharing groups can carry malware.

Support never asks for a password or OTP. Parimatch support does not message first on WhatsApp and does not request login codes in chat. Anyone asking for these details is trying to take over the account.

Account settings also include deposit limits, session reminders, time-outs and self-exclusion. Betting is for adults 18+ only; set limits before the first deposit and read the responsible gambling page if play stops feeling like entertainment.

FAQ About Parimatch Login

Can I log in to Parimatch with an account ID instead of a phone number?

Yes. The login form accepts a +91 phone number, an e-mail or the account number (ID), each with the same password.

What should I do if the Parimatch login OTP does not arrive?

Wait about 60 seconds, check that DND does not block service messages and that the number is typed correctly, then request a new code. If the code still does not come, write to the Online Chat.

Is the same Parimatch account used in the app and in a desktop browser?

Yes. One login opens the same balance, bets and bonuses in a desktop browser, on the mobile version, in the Android app and in the iOS web app.

Why is my Parimatch account locked?

A lock usually follows several wrong passwords in a row or a pending verification check. Contact the 24/7 Online Chat and complete KYC if requested.

Will Parimatch support ever ask for my password or OTP?

No. Support does not request passwords or login codes and does not message first on WhatsApp. Treat any such request as a scam.

Do I need to log in again after updating the Android app?

Accepting the update prompt or installing the latest APK over the old version keeps the account. If the login form appears afterwards, the usual phone, e-mail or ID details work.
